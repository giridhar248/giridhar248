## Selected projects

### [AI Knowledge Assistant](https://github.com/giridhar248/AI-KNOWLEDGE-ASSISTANT)

Multi-agent system for querying personal knowledge bases. RAG over a vector store via LangChain + LangGraph, model-served locally with Ollama. Web UI for upload-and-ask flows.

`Python` · `LangChain` · `LangGraph` · `Ollama` · `FAISS`

### [AI Medical Diagnostics Agents](https://github.com/giridhar248/Medical-Diagnostics-With-Ai-Agent)

Multi-agent diagnostic pipeline on GPT-4o with Python multithreading. Tuned inter-agent message routing dropped response time by ~30%; deployable on Kubernetes for parallel patient-data workloads.

`Python` · `GPT-4o` · `Kubernetes` · `Docker`

### [LangChain RAG — Document Understanding](https://github.com/giridhar248/langchain-rag-retrieval-augmented-generation-for-document-understanding)

Notebook-driven exploration of retrieval-augmented generation. Embedding strategies, chunking, and prompt patterns for grounded LLM responses over arbitrary documents.

`Python` · `LangChain` · `Vector Store`

### [Distributed URL Shortener](https://github.com/giridhar248/url-shortener-service)

High-throughput shortening service in Spring Boot with Redis caching, MySQL persistence, and Nginx load balancing. JMeter-tested at 10K req/min with consistent-hashing key generation; full stack containerized via Docker Compose.

`Java` · `Spring Boot` · `Redis` · `MySQL` · `Docker` · `Nginx`

### [Bank App — Spring Cloud Microservices](https://github.com/giridhar248/bank-app-spring-cloud-microservices)

Microservices banking application on Spring Cloud. Eureka service discovery, centralized config, API gateway, and inter-service communication patterns for a resilient distributed backend.

`Java` · `Spring Cloud` · `Eureka` · `API Gateway`
